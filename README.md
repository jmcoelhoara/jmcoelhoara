### `~/about`

I'm João, a Brazilian living in Metro Vancouver. I finished my **Computer Information Systems** diploma at the University of the Fraser Valley in April 2026. Before that I did a Sales & Marketing diploma, which is probably why I care so much about the person on the other end of the screen.

I've spent the last few years on the other side of the counter: serving customers at an açaí shop, running AV at events, tuning skis at Cypress Mountain. Most of my ideas come from watching small businesses juggle things that software should be handling for them.

```bash
$ cat now.txt
→ IT support: networking, Windows Server / Active Directory, Linux CLI
→ Automating workflows with n8n and Claude Code
→ Exploring AI agents that answer customer messages for small businesses
→ Learning C (pointers are winning, for now)
→ Open to IT and AI roles in Metro Vancouver
```
